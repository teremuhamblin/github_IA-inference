Documentation
=============

Ce dossier regroupe la documentation technique du projet, incluant la
structure, l'architecture et les informations nécessaires à la compréhension
globale du système d'inférence IA.

Contenu
-------

- ``structure.md`` : Description détaillée de l'organisation du projet.
- ``architecture.md`` : Présentation de l'architecture interne et des modules.
- ``README.rst`` : Page d'accueil de la documentation.

Rôle
----

La documentation fournit une vue d'ensemble claire et structurée du projet,
afin de faciliter la compréhension, la maintenance et l'évolution du système.
