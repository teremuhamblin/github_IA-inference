# Politique de prompts — github_IA-inference

## Contenu autorisé
- Code non sensible
- Documentation technique
- Logs anonymisés

## Contenu interdit
- Secrets (tokens, mots de passe, clés privées)
- Données personnelles identifiables
- Configurations de sécurité internes non publiques

## Règles internes vs publics
- Repos publics : prompts neutres, pas de contexte sensible
- Repos internes : prompts taggués avec niveau de sensibilité
