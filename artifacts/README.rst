Artifacts
=========

Ce dossier contient les artefacts générés automatiquement par les workflows
d'inférence IA du projet. Il regroupe les sorties techniques produites lors
des analyses, simulations ou transformations du code.

Contenu
-------

- ``diff.txt`` : Fichier de différences généré par le système d'inférence IA.
- ``README.rst`` : Documentation du dossier et de la nature des artefacts.

Rôle
----

Les artefacts servent de traces techniques, de preuves de génération ou
d'éléments d'analyse pour le suivi des évolutions du projet.
